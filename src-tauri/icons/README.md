# Icône de compilation / Build icon

FR : `icon.png` est une icône RGBA minimale de 128 × 128 pixels représentant une horloge. Elle fournit la ressource locale obligatoire de `tauri::generate_context!()`, absente avant la phase 1. Elle ne remplace aucune icône historique et n'utilise aucun service externe.

EN: `icon.png` is a minimal 128 × 128 RGBA clock icon. It provides the local resource required by `tauri::generate_context!()`, missing before phase 1. It replaces no historical icon and uses no external service.
